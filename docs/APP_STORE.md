# App Store Checklist

## App record

- [ ] Create a new App ID for `br.com.quemsoueu.adivinha`.
- [ ] Create the App Store Connect record `Quem Sou Eu? Adivinha`.
- [ ] Confirm the bundle ID before uploading any build.
- [ ] Configure Games / Trivia and free pricing.

## Build

- [ ] Create the exclusive provisioning profile.
- [ ] Configure the Apple Distribution certificate and secrets.
- [ ] Run the macOS release workflow.
- [ ] Confirm the uploaded build is `VALID` in the correct app.
- [ ] Answer export compliance questions.

## Store metadata

- [ ] Portuguese description and subtitle.
- [ ] Support URL.
- [ ] Privacy policy URL.
- [ ] App Privacy: no data collected.
- [ ] Age rating answered honestly.
- [ ] Content rights confirmed.
- [ ] Review notes explain offline operation and no account requirement.

## Screenshots

- [ ] Capture the final app, not mockups.
- [ ] Use only original mascot and avatars.
- [ ] Do not show third-party logos or copyrighted photographs.
- [ ] Upload accepted iPhone screenshot sizes.
- [ ] Confirm screenshot states are `COMPLETE`.

## Submission

- [ ] Select the correct final build.
- [ ] Check every required field.
- [ ] Submit version 1.0 for App Review.
- [ ] Record version, build, IDs, workflow and date in `PROJECT_STATUS.md`.
